# Description

This snippet will quarantine an asset with the Insight Agent. It takes a list of assets in the form of IP addresses, hostnames, MAC addresses, or asset identifiers, and returns whether each asset was quarantined.

# Requirements

* A connection for the Rapid7 Insight Agent plugin

# Documentation

## Setup

Import the snippet into InsightConnect, then configure the connection for the Rapid7 Insight Agent plugin steps.

## Technical Details

Plugins utilized by snippet:

|Plugin|Version|Count|
|----|----|--------|
|Rapid7 Insight Agent|2.0.1|2|
